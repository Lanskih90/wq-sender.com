# Деплой

Сайт хоститься на **GitHub Pages** з кастомним доменом `wq-sender.com` (файл `CNAME` у корені).

## Як задеплоїти

Достатньо запушити зміни в головну гілку репозиторію:

```bash
git add .
git commit -m "опис змін"
git push
```

Усе. Ніякої збірки, окремої команди деплою чи ручної викладки на сервер не потрібно — проєкт складається зі статичних HTML/CSS/JS, і GitHub Pages віддає файли з репозиторію як є. Через хвилину-дві онлайн-версія https://wq-sender.com оновиться сама.

## Що варто знати

- **Перевіряй локально перед пушем.** Запусти статичний сервер із кореня репозиторію:

  ```bash
  python3 -m http.server 8000    # http://localhost:8000
  ```

  Саме сервер, а не відкриття файлу через `file://` — інакше шляхи на `404.html` не працюватимуть.

- **Кеш браузера.** Одразу після деплою браузер може показувати стару версію стилів чи скриптів. Перед тим як вирішити, що зміна «не застосувалась», зроби hard-reload (Cmd+Shift+R).

- **Усе в репозиторії — публічне.** Файли в корені доступні за прямим URL, тож не комітьте сюди чернетки, бекапи чи щось службове.
